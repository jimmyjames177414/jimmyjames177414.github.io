Open source

Fourteen tools at github.com/jimmyjames177414. The eleven research tools each ship a NOVELTY.md with a written prior-art search and the claims the project may not make.

  • Watching agents work rollcall: which worktree each running AI coding agent owns, and which work nobody owns (write-up). sincelast: tells a coding agent what changed underneath it, before it acts.
  • Honest evaluation errorbars: power analysis and paired confidence intervals for LLM evals (write-up). inconclusive: did the property fail, or did the run just end? knowwhen: a benchmark for whether an agent knows when to ask instead of act (write-up).
  • Measuring context mincontext: delta debugging that shrinks a failing context to the smallest reproducer. Also stopless, stopbench and toolsweep, which measure how much of a prompt or tool schema actually earns its place.
  • Accountability assumptionledger and validwhile: agents that state their assumptions, and memory whose facts carry a check for when they stop being true.
